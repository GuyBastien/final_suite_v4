# final_suite v4

Modules Tryton 7.0 pour hôtel, restaurant et station-service, avec paiement mobile MonCash et NatCash.

Auteur : Pierre Michel Augustin.

## Dossiers

- `modules/` : code source
- `dist/` : paquets pip
- `docs/` : guides (utilisation, administration, technique, déploiement)
- `ui/` : thème pour le client web et le client bureau
- `ui/FrontEnd_GHH/` : page d'accueil du serveur, créée par Thierry Desir ([@thierry509](https://github.com/thierry509))

## Installation

Il faut Tryton 7.0 et PostgreSQL.

```sh
pip install dist/*.whl
```

Les étapes complètes sont dans les guides de déploiement, dans `docs/`.
