Restaurant Module
#################

Tryton 7.0 module to run restaurants and bars: restaurants, areas and tables,
orders (dine-in, bar tab, takeaway, delivery), kitchen and bar screens,
reservations, menu items with recipes, happy hours, payments, delivery drivers,
stock consumption, dashboard and sales report.

Install with ``pip install restaurant-tryton`` then update the database
(``trytond-admin -d DB -u restaurant --all``). Open *Restaurant > Usage Guide*.
