Party Person Haiti
##################

Tryton 7.0 module for Haiti:

* adds Haitian Creole (``ht``) to the languages of Tryton, so that modules
  can ship ``locale/ht.po`` translations;
* adds the first name of natural persons to the parties;
* adds the NIF (Numéro d'Identification Fiscale) and the NINU (Carte
  d'Identification Nationale Unique) to the identifier types of the party
  configuration;
* adds the arrondissement and communal section subdivision types.
